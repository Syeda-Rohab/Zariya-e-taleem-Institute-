Chapter 1 — Web Development ki Duniya
Website, Web Page, Internet, WWW, Browser, Search Engine, URL, Domain, Hosting, Client & Server
▾

1. Website Kya Hoti Hai?

Socho tumhare paas ek school ki notebook hai. Us notebook ke andar bohot saare pages hote hain. Waise hi Website bhi bohot saare Web Pages ka collection hoti hai.

EXAMPLE
  • 📱 Facebook = Website
  • 🎥 YouTube = Website
  • 🛒 Daraz = Website
  • 🛍 Amazon = Website

2. Web Page Kya Hota Hai?

Website ka har alag page Web Page kehlata hai.

EXAMPLE — Facebook
  • Login Page
  • Home Page
  • Profile Page
  • Settings Page

Ye sab milkar Facebook Website banate hain.

3. Internet Kya Hota Hai?

Socho Karachi, Lahore, Islamabad aur duniya bhar ke computers ek doosre se connected hain. Ye bohot bara network hi Internet hai.

Internet ki wajah se tum:

  • YouTube dekh sakti ho
  • Google use kar sakti ho
  • WhatsApp chala sakti ho
  • Online classes le sakti ho

4. WWW (World Wide Web) Kya Hai?

Internet ko ek bohot bara road samjho. Aur Websites ko us road par bane hue ghar. Ye tamam websites milkar World Wide Web (WWW) kehlati hain. Isi liye aksar websites ke shuru mein www likha hota hai.

EXAMPLE

www.google.com

5. Browser Kya Hota Hai?

Browser ek software hai jo HTML, CSS aur JavaScript ko padh kar hume website dikhaata hai.

Mashhoor Browsers:

  • Google Chrome
  • Microsoft Edge
  • Mozilla Firefox
  • Safari
  • Opera
EXAMPLE

Tumne HTML file banayi. Browser us file ko khol kar sundar webpage bana deta hai.

6. Search Engine Kya Hota Hai?

Search Engine aur Browser ek cheez nahi hote.

  • Browser = Website kholta hai
  • Search Engine = Website dhoondta hai

Examples: Google, Bing, DuckDuckGo

Agar tum Google mein likho "HTML Course" to Google tumhare liye websites dhoond kar laata hai.

7. URL Kya Hota Hai?

URL matlab website ka address. Jaise har ghar ka address hota hai, waise hi har website ka bhi address hota hai.

EXAMPLE

https://www.google.com — isay URL kehte hain.

8. Domain Name Kya Hota Hai?

Domain website ka naam hota hai.

EXAMPLE
  • google.com
  • youtube.com
  • daraz.pk

Ye yaad rakhna asaan hota hai.

9. Hosting Kya Hoti Hai?

Website ki files (HTML, CSS, JS, images) ko kisi computer par rakhna padta hai jo 24 ghante online rahe. Us jagah ko Hosting kehte hain. Agar hosting na ho to doosre log tumhari website nahi dekh sakenge.

10. Client aur Server

Client — Jo website dekh raha hai. Yani tum.

Server — Jis computer par website rakhi hoti hai.

EXAMPLE

Tum browser mein google.com likhti ho → Request Server ke paas jaati hai → Server HTML, CSS aur JavaScript bhejta hai → Browser website dikha deta hai.

Is Process ka Diagram:

Tum (Client)
↓
Browser
↓
Internet
↓
Server
↓
HTML + CSS + JS
↓
Browser
↓
Website Screen par

Chapter 2 — HTML Basics
HTML history, HTML5, VS Code setup, pehli HTML file aur uski line-by-line explanation
▾

1. HTML Kya Hai?

HTML ka full form hai: HyperText Markup Language. Ye naam yaad karna zaroori nahi. Bas ye yaad rakho — HTML website ka Skeleton (Haddi) hoti hai.

EXAMPLE

Socho tum ek ghar bana rahi ho. Sabse pehle kya banta hai? 🧱 Eent aur cement ka structure. Uske baad: Paint, Doors, Windows, Decoration.

Bilkul waise hi website mein:

  • HTML = Structure (Haddi)
  • CSS = Design (Kapray & Makeup)
  • JavaScript = Dimagh (Soch aur Actions)

2. HTML Kisne Banayi?

HTML ko Tim Berners-Lee ne 1991 mein banaya. Unka maqsad tha ke log internet par documents aur information asaani se share kar saken.

3. HTML Ki History

  • 1991 → HTML aayi
  • 1995 → HTML 2.0
  • 1997 → HTML 3.2
  • 1999 → HTML 4.01
  • 2014 → HTML5

Aaj hum HTML5 use karte hain.

4. HTML Ki Importance

Agar HTML na hoti to:

  • ❌ Facebook nahi hota
  • ❌ YouTube nahi hota
  • ❌ Daraz nahi hota
  • ❌ Amazon nahi hota

Har website HTML se shuru hoti hai.

5. HTML5 Kya Hai?

HTML5, HTML ka latest aur behtar version hai. Isme naye tags aaye, jaise <header>, <nav>, <section>, <footer>, <video>, <audio>. Ye website banana aur samajhna dono asaan kar dete hain.

6. VS Code Kya Hai?

Visual Studio Code (VS Code) ek free code editor hai. Isme hum HTML, CSS aur JavaScript likhenge.

  • 📒 VS Code = Tumhari Copy
  • ✏️ Code = Tumhari Writing
  • 🌐 Browser = Result

7. Folder Banana

Desktop par ek folder banao: Web Development. Uske andar ek aur folder: HTML. Uske andar: Lesson-1.

FOLDER STRUCTURE
Desktop
│
└── Web Development
      │
      └── HTML
             │
             └── Lesson-1

8. HTML File Banana

Lesson-1 ke andar ek file banao: index.html

Important: Agar file ka naam index.html hai to browser samajh jata hai ke ye website ka main page hai.

9. HTML Ka Pehla Code

HTML
<!DOCTYPE html>
<html>
<head>
    <title>My First Website</title>
</head>
<body>
    <h1>Assalam O Alaikum</h1>
    <p>Main HTML seekh rahi hoon.</p>
</body>
</html>

Har Line Ki Explanation

Line 1 — <!DOCTYPE html>
Browser ko batata hai: "Ye HTML5 document hai."

Line 2 — <html>
HTML ki shuruaat. Poora webpage isi ke andar hota hai.

Line 3 — <head>
Head ke andar wo cheezen hoti hain jo browser ko chahiye hoti hain, lekin user ko page par nazar nahi aati.

Line 4 — <title>My First Website</title>
Ye browser ke tab ka naam hota hai. Agar tum likho <title>Zariya-E-Taleem</title> to browser ke tab par Zariya-E-Taleem likha hoga.

Line 5 — <body>
Body ke andar woh sab kuch aata hai jo user ko page par nazar aata hai — Text, Images, Buttons, Videos.

Line 6 — <h1>Assalam O Alaikum</h1>
Sabse badi heading.

Line 7 — <p>Main HTML seekh rahi hoon.</p>
Paragraph.

Line 8 — </body>
Body khatam.

Line 9 — </html>
HTML document khatam.

BROWSER MEIN OUTPUT
OUTPUT
Assalam O Alaikum

Main HTML seekh rahi hoon.

Chapter 3 — HTML Tags
Tags, Elements, Empty Tags, Headings, Paragraph, Line Break, Comments, Attributes
▾

Tag Kya Hota Hai?

Tag browser ko instruction deta hai.

EXAMPLE
  • <h1> = Heading banao
  • <p> = Paragraph banao
  • <img> = Image dikhao
  • <a> = Link banao

HTML Element

HTML
<h1>Zariya-E-Taleem</h1>

Isme: <h1> = Opening Tag, Zariya-E-Taleem = Content, </h1> = Closing Tag. In teeno ko mila kar Element kehte hain.

Empty Tags

Kuch tags ko closing tag ki zarurat nahi hoti.

HTML
<br>\n<hr>

Ye Empty Tags kehlate hain.

Headings

HTML mein 6 headings hoti hain.

HTML
<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

Rule: <h1> sabse badi heading hoti hai, <h6> sabse chhoti. Ek page par sirf ek <h1> rakhna best practice hai.

Paragraph

HTML
<p>Ye mera pehla paragraph hai.</p>
<p>Ye mera doosra paragraph hai.</p>

Har <p> ek naya paragraph banata hai.

Line Break

Agar line change karni ho:

HTML
Pakistan<br>
Karachi<br>
Sindh
OUTPUT
OUTPUT
Pakistan
Karachi
Sindh

Horizontal Line

HTML
<h1>Zariya-E-Taleem</h1>
<hr>
<p>Free Courses</p>
OUTPUT
OUTPUT
Zariya-E-Taleem
──────────────
Free Courses

Comments

Comments browser mein show nahi hote. Sirf programmer ke liye note hote hain.

HTML
<!-- Ye meri heading hai -->
<h1>Hello</h1>

Attributes

Attributes tag ko extra information dete hain.

HTML
<p title="Ye paragraph hai">
Hello
</p>

Yahan: Tag = p, Attribute = title, Value = "Ye paragraph hai"

Syntax:

HTML
Tag Attribute="Value"

2. alt Attribute

Agar image load na ho to alt ka text dikhai deta hai.

HTML
<img src="cat.jpg" alt="White Cat">

Agar image delete ho jaye to browser "White Cat" likh dega.

3. Width aur Height

Image ka size change karne ke liye:

HTML
<img src="cat.jpg" width="300">

Ya:

HTML
<img src="cat.jpg" width="300" height="200">

form, input types, checkbox, radio, textarea, button, label, registration form project
▾

Form Kya Hota Hai?

Form wo hota hai jahan user apni information enter karta hai.

EXAMPLE
  • Login Page
  • Sign Up Page
  • Contact Us
  • Admission Form
  • Job Application

Ye sab HTML Form se bante hain.

1. <form> Tag

Har form ki shuruaat <form> se hoti hai.

HTML
<form>
</form>

Iske andar saare input fields aate hain.

2. <input> Tag

Input user se data lene ke liye hota hai.

HTML
<input type="text">

Isme user apna naam likh sakta hai.

3. Placeholder

Placeholder ek hint hota hai.

HTML
<input type="text" placeholder="Apna Naam Likhen">
OUTPUT
┌──────────────────────────┐
| Apna Naam Likhen         |
└──────────────────────────┘

Jaise hi user likhna shuru karega, ye text gayab ho jayega.

4. Name Field

HTML
<input type="text" placeholder="Full Name">

5. Email Field

HTML
<input type="email" placeholder="Email">

Browser samajh jata hai ke yahan email likhni hai.

6. Password Field

HTML
<input type="password" placeholder="Password">
OUTPUT
********

Password chhup jata hai.

7. Number Field

HTML
<input type="number" placeholder="Age">

Sirf numbers enter karne ke liye.

8. Date Field

HTML
<input type="date">

9. Checkbox

Ek se zyada options select karne ke liye.

HTML
